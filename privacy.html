Политика конфиденциальности

Действует с 13 ноября 2026 г.

Коротко: Beaconvale — одиночная игра. В ней нет аккаунтов, регистрации, мультиплеера, чата, рекламы, аналитики и встроенных покупок. Игра не собирает, не передаёт и не продаёт ваши персональные данные. Прогресс и настройки хранятся только на вашем устройстве.

1. О ком эта политика

Политика относится к игре Beaconvale — приложению для Windows из Microsoft Store и версии для Steam — и к этому сайту. Игру разрабатывает и выпускает независимый разработчик LooT RooM (далее — «мы»). Связаться с нами: lootroomgame@gmail.com.

2. Какие данные хранит игра и где

Чтобы вы могли продолжить игру, она сохраняет на вашем компьютере:

  • прогресс: имя героя, которое вы вводите сами (оно не обязано быть настоящим), класс, уровень, предметы, ход истории и полученные достижения;
  • настройки: язык, громкость, качество графики, сложность, состояние обучения и управления, размер окна.

Эти данные лежат в папке приложения в профиле пользователя Windows (у версии для Steam на macOS и Linux — в папке пользователя этих систем). Они не покидают компьютер: мы их не получаем и не видим. Удалить их можно в самой игре (новый герой) или удалением приложения.

Если вы сами экспортируете сохранение в файл или загружаете его из файла (меню «Сохранения»), файл создаётся и читается только на вашем компьютере, в том месте, которое вы выберете.

3. Работа без интернета

Игра полностью работает без подключения к интернету и ничего не загружает из сети во время игры.

4. Чего в игре нет

Игра не использует cookie, рекламу, счётчики, системы аналитики, сторонние скрипты и шрифты из интернета, не запрашивает доступ к местоположению, камере, микрофону, контактам и файлам (кроме файла сохранения, который вы выбираете сами). В игре нет общения с другими игроками и сетевых функций.

5. Этот сайт

Сайт размещён на GitHub Pages (GitHub, Inc.). Он только рассказывает об игре и запоминает в вашем браузере выбранный язык страницы. Как любой веб-хостинг, GitHub может обрабатывать технические сведения о запросах, например IP-адрес, чтобы обеспечивать работу и безопасность сервиса. Это происходит по заявлению о конфиденциальности GitHub; у нас нет доступа к этим сведениям.

6. Магазины приложений

Если вы получаете игру через Microsoft Store или Steam, данные о вашей учётной записи, покупке и установке обрабатывают Microsoft и Valve по своим политикам конфиденциальности. Магазины могут предоставлять нам только обобщённую статистику (например, число установок и отчёты о сбоях), по которой нельзя узнать вас.

Версия для Steam сообщает Steam о полученных игровых достижениях, чтобы они появились в вашем профиле Steam. Другие данные игра в Steam не передаёт.

7. Дети

Игра не собирает персональные данные ни у кого, включая детей.

8. Изменения

Если политика изменится, мы обновим эту страницу и дату вступления в силу вверху.

9. Контакты

Вопросы о конфиденциальности: lootroomgame@gmail.com.

Privacy Policy

Effective 13 November 2026

In short: Beaconvale is a single-player game. It has no accounts, sign-up, multiplayer, chat, ads, analytics or in-game purchases. The game does not collect, share or sell your personal data. Your progress and settings stay on your device.

1. Who this policy covers

This policy covers the game Beaconvale — the Windows app from the Microsoft Store and the Steam version — and this website. The game is developed and published by the independent developer LooT RooM ("we"). Contact: lootroomgame@gmail.com.

2. What the game stores and where

So that you can continue playing, the game stores on your computer:

  • progress: the hero name you type in (it does not have to be your real name), class, level, items, story progress and earned achievements;
  • settings: language, volume, graphics quality, difficulty, tutorial and control preferences, window size.

This data is kept in the app's folder in your Windows user profile (for the Steam version on macOS and Linux, in your user folder on those systems). It does not leave your computer: we do not receive or see it. You can delete it in the game (new hero) or by uninstalling the app.

If you export your save to a file or load it from a file (the Saves menu), the file is created and read only on your computer, in the place you choose.

3. Playing offline

The game works fully without an internet connection and downloads nothing while you play.

4. What the game does not do

The game uses no cookies, ads, counters, analytics, third-party scripts or web fonts, and does not ask for your location, camera, microphone, contacts or files (other than a save file you pick yourself). There is no communication with other players and no online features.

5. This website

This website is hosted on GitHub Pages (GitHub, Inc.). It only tells you about the game and remembers the page language you picked in your browser. Like any web host, GitHub may process technical request data, such as IP addresses, to operate and secure the service, under the GitHub General Privacy Statement. We have no access to that data.

6. App stores

If you get the game through the Microsoft Store or Steam, your account, purchase and installation data are handled by Microsoft and Valve under their own privacy policies. The stores may give us only aggregated statistics (such as install counts and crash reports) that cannot identify you.

The Steam version tells Steam which in-game achievements you have earned, so that they appear on your Steam profile. The game sends no other data to Steam.

7. Children

The game does not collect personal data from anyone, including children.

8. Changes

If this policy changes, we will update this page and the effective date at the top.

9. Contact

Privacy questions: lootroomgame@gmail.com.
